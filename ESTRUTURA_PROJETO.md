# Estrutura do projeto

A pasta base do Java segue o padrão do projeto original:

```text
src/main/java/br/ueg/trindade/eduarda_mygarden_fullstack/
├── EduardaMygardenFullstackApplication.java
├── config/
├── controller/
├── dto/
├── model/
├── repository/
├── service/
└── util/
```

A classe principal permanece no pacote base `br.ueg.trindade.eduarda_mygarden_fullstack`.
As demais classes ficam separadas nos pacotes `controller`, `service`, `repository` e `model`, conforme o checklist da N1 e a Aula 06.
