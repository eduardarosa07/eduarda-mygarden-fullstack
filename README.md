# 🌱 My Garden

O **My Garden** é um sistema web criado para ajudar na organização de tarefas do dia a dia de uma forma mais visual e motivadora.

A ideia principal é separar as tarefas por áreas, como **Estudos, Casa, Trabalho e Pessoal**. Cada área possui uma planta, que cresce conforme as tarefas são concluídas.

## ✨ Funcionalidades

- Cadastro de usuários
- Login no sistema
- Cadastro de permissões
- Criação de seções
- Cadastro e gerenciamento de tarefas
- Marcar tarefas como concluídas
- Acompanhamento do progresso das seções
- Crescimento das plantas conforme o progresso

## 🛠️ Tecnologias utilizadas

- **Java 21**
- **Spring Boot**
- **H2 Database**

## 🌿 Como funciona

O usuário cria uma seção, como **Estudos**, e adiciona tarefas relacionadas a ela.

À medida que as tarefas são concluídas, o sistema calcula o progresso da seção e a planta cresce, representando visualmente a evolução do usuário.

> Pequenos cuidados fazem grandes coisas crescerem. 🌱
