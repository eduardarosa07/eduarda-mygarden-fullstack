# Sugestão de commits para a N2

O PDF pede commits regulares no GitHub. Não faça um único commit com tudo se ainda estiver desenvolvendo. Uma sequência natural seria:

1. `git commit -m "Adiciona entidades Habito e RegistroHabito"`
2. `git commit -m "Implementa CRUD e relacionamento de habitos"`
3. `git commit -m "Adiciona telas de habitos e registros"`
4. `git commit -m "Implementa autenticacao com Spring Security e JWT"`
5. `git commit -m "Adiciona validacao e upload de imagem"`
6. `git commit -m "Adiciona configuracao Docker para N2"`
7. `git commit -m "Finaliza ajustes e documentacao da N2"`

Use apenas commits que correspondam ao trabalho realmente colocado no repositório naquele momento.
